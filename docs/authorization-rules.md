# 授权套餐与在线、静默规则

本批为本地源码改动，尚未发布安装器。终端与主题中心完成联测；打包器、影视中心客户端未在本批改造。

## 套餐与签发

授权中心展开“授权套餐”，可新增、编辑、删除套餐。套餐规定产品、天/月/年/永久期限、在线或静默或跟随全局、域名要求、各产品名额与下载/打包权限。签发时选择套餐并填写名称、域名即可；无套餐时保留自定义签发。

签发记录保存套餐快照和版本。套餐修改只影响新签发，删除套餐不删除已有 Key。提交旧套餐版本返回409，刷新后重新选择；月/年期限按日历计算，月底及闰年取目标月份有效日期。永久用远期许可表达，仍可联网撤销。客户端无法用自定义请求伪造套餐快照。

## 在线管理

首次激活必须联网。保存 Key 后每次启动均询问终端，启动网络请求共享3秒预算。新签名许可从最后一次成功认证起最多72小时，且不超过商业授权期限；离线启动不刷新该期限。超过许可期限锁定受限业务。

运行中SSE通知触发重新认证，另有60秒轮询。通知及普通HTTP错误本身不作为撤销凭据；客户端收到验证签名、身份、nonce和时间的可信拒绝后立即保存拒绝并锁定，重启不能绕过。网络不通与授权被拒绝分别处理。不存在对断网设备即时远程撤销；联网传播受连接状态与请求耗时影响。

旧 online 许可没有新宽限字段，保留旧严格认证新鲜度规则，下一次成功认证更新许可。

## 静默本地

首次激活联网，随后凭签名许可在授权期限内运行。每次启动后台询问终端，网络失败不弹窗，不妨碍有效许可下的本地操作。新配置默认每小时重连；已有终端保存的重连周期不自动覆盖，可在策略面板修改。离线迁移按许可权限执行，联网恢复后同步身份和事件。

可信拒绝仍会锁定，静默不能掩盖明确撤销。已断网设备须恢复连接后才能获知撤销或模式变化。

## 自动授权日志

日志自动记录，默认最近7天，支持所有时间、高级筛选、分页、当前页CSV导出；没有手工添加日志表单。包括Key编号及名称、产品、已记录版本、设备/激活身份、事件与结果、发生和接收时间、IP及国家来源。

国家是IP推断结果，无法推断时显示未知。离线补传只能可靠记录重连时来源IP，不声称它是离线操作时IP；未记录的历史版本不使用当前绑定版本补造。删除授权保留撤销与审计记录。迁移包保留套餐、许可身份、签名密钥与历史数据。
