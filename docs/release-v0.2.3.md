# 河豚终端 v0.2.3

## 新增

- 打包器、主题中心、影视中心各自独立的版本分类与发布历史。
- 产品源码、APP源码、主题模板和成品安装包目录及兼容说明。
- GitHub公开仓库提交与Release检查，校验制品后导入草稿。
- 全局和单客户在线授权、静默本地策略与签名配置。
- 加密整包迁移，保留原签名身份、管理员密码和业务资源。
- 迁移维护开关、业务写入冻结、有限宽限期和迁移取消/完成。
- 正式/备用授权地址身份验证、签名下发和真实客户端回执。

## 安装与更新

源码包包含服务器、网页界面、部署配置和Linux安装管理脚本，需按README与docs/linux-install.md安装。此版本为服务端发布，不含桌面EXE或预构建Docker镜像；安装脚本在服务器本地构建容器。

已有Linux安装执行 `hetun update`（非root使用 `sudo hetun update`），会自动备份、构建并检查服务；失败尝试回退。更新操作不会替代域名入口部署。

迁移前阅读docs/migration.md，保管迁移密码和备份，仅保持一个业务写入实例。导入只支持空白目标实例。

## 对接边界

三个产品的实际客户端仍需分别接入授权策略、地址获取、更新安装与记录上报。完全离线的客户端只能在恢复联网后接收新配置。现有占用80/443的Docker入口自动对接问题未在本次发布中解决。

## 验证

发布功能源码已通过39项Node测试、26个脚本检查及本地日夜界面验收；GitHub Actions验证服务测试、Linux脚本、Docker和Nginx路由。
