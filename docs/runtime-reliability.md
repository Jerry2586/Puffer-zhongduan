# 终端运行保护与退出

本轮是单实例部署的可靠性加固，保持外部 JSON 存储。多管理员、数据库迁移、跨服务器高可用与三个产品的完整接入不属于本轮已完成能力。

## 单实例运行

createTerminal 在打开数据库之前获取运行目录的实例保护。目录先经过 realpath 解析，Windows 比较时忽略大小写。重复实例启动失败，不能覆盖数据库或重置运行任务。

Windows 使用按目录摘要命名的本机命名管道；Linux 使用按目录摘要确定的回环 TCP 保护端口（16000–63999），不作为业务入口、不需要安全组开放。Linux 保护端口与其他程序发生碰撞时拒绝启动，不能据此直接断言已有终端实例；先检查报错与已有进程。进程结束后由操作系统释放监听，无需删除遗留锁文件。

保护范围是同一操作系统／网络命名空间。不同 Docker 容器具有独立网络空间，不能依赖此保护跨容器互斥。正式部署仍须只有一个终端容器写入数据卷，禁止旧新容器同时写同一目录。直接调用 openStore 的内部脚本不获取实例保护，只能在服务停止后进行维护；测试中的直接调用不代表正式运行方式。

## 授权通知

/v1/license/watch 先鉴权再建立 SSE。总连接最多1000，同一个激活身份最多3个；15秒心跳。断开、写入异常或响应缓冲已满时释放连接，避免慢客户端无限积压。客户端必须保留重连和周期认证作为补偿，SSE 消息不携带授权许可。

授权、绑定、全局授权策略、终端设置及迁移相关修改成功后发出重新认证提示。失败请求、登录、公告发布、软件版本发布不会发出授权提示。设置修改目前按整个设置接口通知；客户端自身定时检查公告和软件更新，不能把授权事件当成完整消息推送协议。

在线撤销由客户端收到提示或下次认证后生效。网络断开时无法承诺即时撤销；静默模式仍按可信签名许可和重连结果执行。

## 启动和退出

初始化失败、业务监听端口冲突会释放实例保护。SIGINT/SIGTERM 触发统一关闭；重复关闭共享同一关闭流程。关闭时停止维护定时器、断开 SSE、停止接受新连接，给剩余 HTTP 连接5秒退出时间，然后断开残留连接，并等待已经接收的串行写入结束后释放实例保护。

5秒是连接清理期限，不是持久化任务的强制终止期限。正在写入的任务仍须完成或失败；不要强杀后声称数据已全部保存。强制终止依赖既有原子写入和下次启动恢复，不能提供业务请求必然完成的保证。
